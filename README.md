## How it works

- Reads public RSS feeds, official article pages, and the Hugging Face API.
- Uses a rolling 14-day discovery window and canonical URLs to remove duplicates. Matching titles on the same date are grouped to reduce cross-posts.
- Limits entries per source; filters arXiv titles by configurable topics. This is a selected digest, not an exhaustive release tracker.
- Checks for weight files and reports the declared license and access restrictions. Repositories without declared licenses, adapters, common quantization tags, and intermediate checkpoints are excluded by default. Repository creation is a discovery signal, not a verified model launch date. Open weights do not automatically mean an open-source or commercially permissive license.
- Shows short publisher excerpts when available. These are not LLM-generated summaries; the bot needs no paid API key. Source text is kept in its original language.
- Archives entries on the day they are first collected. Multiple runs on the same day append to that digest.
- Updates files only when it finds unseen entries in the selected recent results. A quiet day produces no commit; repeating the same selection produces no commit either.
- Logs unavailable sources. Partial coverage publishes valid entries and flags the workflow; total failure preserves existing files.

## Run locally

Requires Python 3.11 or newer. No third-party packages are needed.

```sh
python radar.py --dry-run
python radar.py
python -m unittest discover -s tests -v
```

Exit codes: `0` for complete collection, `1` for total source failure or an execution error, `2` for partial coverage. A dry run never writes the digest or its state.

## GitHub setup

1. Publish this folder as a repository on the `mairu1` account, with these files on its default branch.
2. Open **Actions → Daily AI Radar → Run workflow** for an initial collection.
3. The workflow then runs daily at **08:17 Europe/Paris**. GitHub scheduling can be delayed.

The workflow uses the repository's built-in `GITHUB_TOKEN` with `contents: write`. No personal access token or external server is required. Repository rules that prevent direct pushes to the default branch must allow the automation or use a pull-request-based publishing approach.

Generated commits name `mairu1` as author using the account's GitHub noreply email; the committer is `github-actions[bot]`. The commit message and digest explicitly identify automated collection. If you move this project to another account, update `RADAR_AUTHOR_NAME` and `RADAR_AUTHOR_EMAIL` in the workflow to an email linked to that account. Contribution visibility follows [GitHub's contribution criteria](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference).

To pause automatic collection, disable **Daily AI Radar** in the Actions tab. GitHub can also disable scheduled workflows in inactive public repositories; check the Actions tab if collection stops.

## Customize

Edit [config.json](config.json) to change sources, model publishers, research topics, the lookback window, and per-run limits. HTML collectors depend on source markup; their logs indicate when extraction stops working. The collector inspects at most 24 article links per page and 40 recent repositories per model publisher on each run.

The script stores collected entries in [data/entries.json](data/entries.json), uses them to deduplicate future runs, and builds [daily archives](digests/README.md). Keep this state file when moving the project.
